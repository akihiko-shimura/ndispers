# Glasses

Optically isotropic media — glasses and cubic crystals alike. Having one
refractive index with no direction dependence, their methods take
`(wl_um, T_degC)` and no angle or polarization. `CaF₂` is a crystal and is
here because it is cubic; see [Conventions](../conventions.md) for the split.
