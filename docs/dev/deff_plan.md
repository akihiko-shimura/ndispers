| mixin | 適用済み | 未適用の非中心対称結晶 |

## 1. 拡張の前に直すもの（ブロッカー）

Miller 則は**主軸系のテンソル成分**に対して定義される:
d_ijk = δ_ijk · χ_ii(ω₃) χ_jj(ω₂) χ_kk(ω₁)（各 χ は n_x, n_y, n_z のいずれか）。
現行コードはこれを 3 箇所で破っている。

### (a) `delta31` / `d31_sfg` が位相整合角の n を使っている

`_uniax_neg_3m.py:127` は `pmAngles_sfg` を呼んで θ_pm を求め、`n(wl3, θ_pm, 'e')` を χ₃₃ として使う。
i = z（ijk = zxx）に対応する主軸感受率は θ = 90° の n_e であって、θ_pm の混合屈折率ではない。

δ は基準波長対の θ_pm で抽出し、目的波長対の θ_pm で再適用するので誤差は打ち消さない。
β-BBO Eimerl1987, d31 の SHG（現行 vs 主軸）:

| λ (µm) | 現行 | 主軸 | 比 |
|---|---|---|---|
| 0.6 | 0.04349 | 0.04602 | 0.945 |
| 0.8 | 0.04144 | 0.04215 | 0.983 |
| 1.064 | 0.04000 | 0.04000 | 1.000 |
| 2.0 | 0.03624 | 0.03645 | 0.994 |

基準から離れるほどずれる。これはまさに今回追加したい「波長依存性」そのものの精度。

### (b) 同じ経路が例外を出す

`pmAngles['ooe']['theta'][0]` は ooe 解が無いと **IndexError**。
β-BBO の 0.4 µm SHG（→ 0.2 µm）で実際に落ちる:

```
IndexError: list index out of range  (_uniax_neg_3m.py:127)
```

CLBO/KDP/LB4 を任意波長対で扱うようになると常態化する。

### (c) `Uniax_neg_32.d14_sfg` の χ が e 波になっていない

`theta_rad = 0` で `pol='e'` を評価している。θ=0 では n_e ≡ n_o なので、
`chi_wl1e` / `chi_wl3e` は名前に反して常波の χ。
KBBF が `_d14_1064shg = 0.0` を持つため今は露見していない。

なお Kleinman 対称下で 32 の d14 は恒等的に 0（クラス docstring 自身がそう論証している）。
**`delta14` / `d14_sfg` は削除**し、`deff_sfg` の d14 項も落とすのが筋。非 Kleinman を扱う予定ができたら戻す。

### 修正

χ を全て主軸 n で評価する 1 つのヘルパに集約する:

```python
def _chi(self, wl, T_degC, axis):   # axis: 'o' -> n_o, 'e' -> n_e(theta=90)
    th = 0.5*np.pi if axis == 'e' else 0.0
    return self.n(wl, th, T_degC, pol=axis)**2 - 1
```

これで (a) 正しくなり、(b) `pmAngles_sfg` 依存が消えて例外も無くなり、
おまけに `apps/phasematching.py:354` の φ スイープ（約 360 点 × brentq 求根）が Pyodide 上で桁で速くなる。

**順序は譲れない。** 先に展開すると、壊れたパターンを 10 クラスに転写することになる。
このリポジトリが繰り返し生んできたバグ種そのもの。

## 2. ボイラープレート畳み込み

現在 7 結晶が同じ 2 メソッドを、自分の基準値と `1.064` をハードコードするためだけに再宣言している:

```python
def d22_sfg(self, wl1o, wl2o, T_degC):
    return super().d22_sfg(wl1o, wl2o, T_degC,
                           delta22=self.delta22(self._d22_1064shg, 1.064, 1.064, T_degC))
```

クラス属性のデータ 1 行に置き換える:

```python
class BetaBBO(Uniax_neg_3m):
    _d_ref = {"d22": (2.2, 1.064, 1.064),    # pm/V, wl1, wl2 (µm)
              "d31": (0.04, 1.064, 1.064)}
```

mixin 側が `_d_ref` を読んで δ を求め、`d22_sfg(wl1, wl2, T)` を提供する。
14 メソッド消える。結晶追加が 1 行のデータになる。

> これは v1.0 に先送りした**結晶定義のデータ化とは別物**。Sellmeier 係数には触らない。
> 非線形係数は元々「参照値 1 点」しか持たないので、そもそもデータでしかない。

## 5. 理論ノートとレビュー結果

背景理論は `docs/dev/deff_theory.tex`（revtex4-2, `latexmk -pdf` でビルド）にまとめた。
Kleinman 対称、3m/32 のテンソル形、主軸系での Miller 則、歩行角込みの偏光ベクトル、
d_eff の導出、実装対応表、適用限界。ノートを書いて確定したこと:

- **d_eff の幾何因子は 3m・32 とも導出と一致**（式 (14)–(17)）。全体符号がノートの規約と −1 だけ違うが |d_eff| には無関係。
  段階 1 では `deff_sfg` の幾何因子に触らない。
- **歩行角の符号規約** `theta + rho` は正しい。`woa_theta_expr` は `atan(-∂n/∂θ / n)`、
  負単軸 e 波は θ とともに n が減るので ρ > 0（θ=45° で +4.02°）。正単軸でも同式で ρ < 0 となり場合分け不要。
- **縮約表記の因子 2**（非対角の E_j E_k に付く）は d_eff の射影で落としてはいけない。段階 3・4 で新しい群を起こすときの転写ミスの定番。
- **温度**: χ は渡された T で評価される。基準 d は室温値で δ に温度係数は仮定しない。抽出と再適用で同じ T を使う限り自己整合。
- **Miller 則の実験的裏付け**（手元 PDF で照合済み）: Alford & Smith, JOSA B 18, 524 (2001) は BBO・KDP・LiNbO₃ で
  「一致良好」、KTP は再解釈込みで整合、LBO はデータ不足で判定不能。Shoji et al., JOSA B 14, 2268 (1997) は
  KTP の Δ₁₅ が 1.06 vs 1.31 µm で 35% 違うなど「Δ はほとんど一定でない」と警告。ノート §IV・§VIII に両論併記し、
  「~10%」のような根拠のない数値は書かない。
- **文献値** 段階 3・4 の基準 d 値と d_eff 表式の出典が未確定。
- **リリース** apps は PEP 723 で `ndispers==0.9.1` を PyPI から固定している。
  PyPI に上がるまでデプロイ済み計算機には届かない。
